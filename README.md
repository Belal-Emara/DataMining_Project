# Car Data Mining & Intelligent Analytics

A comprehensive data mining project that analyzes a real-world car dataset using clustering, fuzzy logic, and genetic algorithms to discover patterns and build an intelligent decision-support pipeline.

## 📊 Project Overview

This project applies the complete data mining workflow to a car dataset, including data exploration, preprocessing, clustering, fuzzy inference, and optimization. The objective is to uncover meaningful insights about vehicles and demonstrate how multiple AI techniques can be combined into a unified analytical system.

## 🚀 Features

- 📈 Exploratory Data Analysis (EDA) with visualizations
- 🧹 Data preprocessing (missing values, outliers, encoding, and feature scaling)
- 🎯 K-Medoids clustering with optimal cluster selection
- 🌳 Hierarchical clustering using multiple linkage methods
- 🧠 Fuzzy Logic Inference System for intelligent vehicle evaluation
- 🧬 Genetic Algorithm for optimization and parameter tuning
- 🔄 End-to-end data mining pipeline integrating all project components

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Scikit-Learn Extra (K-Medoids)
- Scikit-Fuzzy
- Jupyter Notebook

## 📂 Dataset

The project uses a real-world **car dataset** containing over **1,000 vehicle records** with both numerical and categorical features, enabling comprehensive data mining and intelligent analysis.

## 📌 Project Outcome

The project identifies natural groups of vehicles, builds a fuzzy logic system for vehicle evaluation, and optimizes the analytical pipeline using a genetic algorithm, demonstrating a complete end-to-end data mining solution.
